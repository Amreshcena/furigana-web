    How it works

    1. 1

      Upload

      One file, several files, or every episode of a season at once.

    2. 2

      Segment & read

      Each line is parsed at the word level, so 調査兵団 and 救ってみせる come back as single units instead of being split mid-word.

    3. 3

      Download

      Get the same .srt back with 漢字[かんじ] tags, ready for Memento or Migaku.

    Prefer to run it yourself?

    The same engine behind this page runs from the command line, no upload needed — good for large batches or if you'd rather keep files local.

    pip install sudachipy sudachidict_core jaconv
python srt_furigana.py ./season1/

    Processing happens on the server — files aren't stored after your download finishes.
